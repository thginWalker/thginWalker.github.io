# thginWalker.github.io

thginWalker 的 GitHub Pages 个人博客站点仓库（静态部署产物）。

## 站点简介

- 生成器：[Hexo](https://hexo.io) 8.1.1
- 主题：Landscape（默认主题）
- 当前内容：默认的「Hello World」示例文章（2026-02-16）

## 目录结构

| 路径 | 说明 |
| --- | --- |
| `index.html` | 博客首页 |
| `2026/02/16/hello-world/` | 示例文章页 |
| `archives/` | 归档页（按年 / 月） |
| `css/` | 主题样式与横幅图（`css/images/banner.jpg`） |
| `js/` | jQuery 与主题脚本（搜索、分享、返回顶部等） |
| `fancybox/` | 图片灯箱插件 |

## 说明

本仓库仅存放 Hexo 生成后的静态文件（即 `hexo deploy` 的输出），不包含博客源码（`_config.yml`、`source/_posts/`、主题目录等）。撰写文章需要在本地 Hexo 项目中完成，然后重新生成并部署到本仓库。
